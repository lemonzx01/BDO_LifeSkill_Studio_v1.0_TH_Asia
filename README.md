# BDO Life by BloodMoon TH (Asia)

เว็บคำนวณต้นทุน–กำไร–ROI ของสูตร Life Skill ใน Black Desert Online (เซิร์ฟเวอร์ Asia)
จากราคาตลาดกลางแบบสด ต่อยอดจากไฟล์ Excel `BDO_LifeSkill_Studio_v2.0_TH_Asia.xlsx`

แผนงานทั้งหมดอยู่ใน [PLAN.md](PLAN.md)

## เริ่มใช้งาน

```bash
npm install
npm run import:data   # ดึงสูตร/ชื่อไอเท็ม/ไอคอน (ครั้งแรก หรือเมื่อมีแพตช์ใหญ่)
npm run dev           # http://localhost:3000
```

## หน้าต่าง ๆ

| หน้า | ใช้ทำอะไร |
|---|---|
| `/` หน้าแรก | การ์ด "วันนี้ควรทำอะไร": แปรธาตุ/ทำอาหาร/แปรรูป/กล่องราชวังที่คุ้มสุด 5 อันดับ และของที่ตลาดขาด คิดจาก Mastery ของแต่ละคน + ตั้งค่าครั้งแรก (Mastery, Value Pack) |
| `/recipes` คำนวณสูตร | ตารางเต็มทุกสูตร ตัวกรอง/เรียง รายละเอียดวัตถุดิบ แผนผลิต ส่งออก CSV |
| `/market` สแกนตลาด | "แนะนำวันนี้" 3 กล่อง (เทรดได้กำไร / น่าซื้อเก็บ / น่าขายตอนนี้) โหมด "ฉันอยากจะ…" และตารางทั้งตลาด |
| `/inventory` คลังของ | ของที่มี ต้นทุนที่จ่าย นำเข้า/ส่งออก CSV |
| `/calc` คิดภาษี | ซื้อราคานี้ ขายราคานี้ กี่ชิ้น → ภาษี เงินที่ได้รับ กำไร/ขาดทุน ราคาเท่าทุน เลือกช่องราคาจริงของไอเท็มในตลาดได้ |
| `/help` วิธีใช้ | คู่มือสั้น ๆ ทุกหน้า สำหรับส่งให้สมาชิกใหม่ |

ตัวกรอง/การเรียง/โหมดของแต่ละหน้าจำไว้ในเบราว์เซอร์ เปิดมาเจอแบบเดิม · หัวตารางติดอยู่ด้านบนตอนเลื่อนบนจอกว้าง

- **ค้นหาด่วน** กด Ctrl+K (หรือปุ่ม "ค้นหา" ในเมนู) จากทุกหน้า พิมพ์ชื่อไอเทม แล้วกระโดดไปดูสูตร / ดูในตลาด / คิดภาษี ได้ทันที
- **ปักดาว ★** ที่แถวในหน้าคำนวณสูตรหรือสแกนตลาด ของที่ปักจะขึ้นบนหน้าแรกในกล่อง "ของที่ฉันเฝ้า" พร้อมราคาปัจจุบัน ของค้างขาย และกำไรถ้าทำเอง (เก็บกับบัญชี ใช้ได้ทุกเครื่อง)

ทุกหน้าใช้บนมือถือได้: จอแคบจะแสดงเป็นการ์ดแทนตาราง เมนูเลื่อนซ้ายขวา และเพิ่มลงหน้าจอหลักได้ (PWA)

## ล็อกอินและสมาชิก

- เปิดเว็บครั้งแรกจะพาไปหน้า `/setup` เพื่อสร้างบัญชี **แอดมินใหญ่คนแรก** (มีได้ครั้งเดียว ตอนยังไม่มีผู้ใช้)
- แอดมินสร้างบัญชีให้สมาชิกที่หน้า `/admin` (ชื่อผู้ใช้ + รหัสผ่านชั่วคราว + สิทธิ์) สมาชิกล็อกอินครั้งแรกจะถูกบังคับตั้งรหัสใหม่
- สิทธิ์ 3 ระดับ: **แอดมินใหญ่** (owner) จัดการได้ทุกบัญชี ตั้งระดับให้ใครก็ได้ และโอนตำแหน่งให้คนอื่นได้ (ตัวเองจะกลายเป็นแอดมินเล็ก) · **แอดมินเล็ก** (admin) สร้าง/ปิด/ลบ/รีเซ็ตรหัสได้เฉพาะสมาชิก · **สมาชิก**
- ปิดใช้งานบัญชี = session ทั้งหมดของคนนั้นถูกยกเลิกทันที เปิดกลับได้ · ลบ = ถาวร · ต้องเหลือแอดมินใหญ่ที่เปิดใช้งานอย่างน้อย 1 คนเสมอ (ระบบเก่าที่มีแต่แอดมิน: คนแรกจะถูกยกเป็นแอดมินใหญ่ให้อัตโนมัติ)
- ฐานข้อมูล: ตั้ง `DATABASE_URL` (Postgres เช่น Neon หรือ Supabase — รับชื่อ `POSTGRES_URL` ด้วย) ใน `.env.local` หรือ Vercel env · ถ้าไม่ตั้ง จะใช้ **PGlite** (Postgres ฝังตัว) เก็บที่ `.data/pglite` สำหรับพัฒนาบนเครื่อง · ตารางถูกสร้างอัตโนมัติ ไม่ต้องรัน migration
- หน้า `/admin` แสดงอายุฐานข้อมูลสูตร และแอดมินใหญ่มีปุ่ม "สำรองข้อมูลทั้งหมด" (บัญชี ตั้งค่า คลังของทุกคน เป็นไฟล์ JSON เดียว)
- รหัสผ่านเก็บแบบ bcrypt, session เป็น cookie httpOnly อายุ 30 วัน, ล็อกอินผิด 10 ครั้งใน 15 นาทีจะถูกพักชั่วคราว

## คลังของและตั้งค่า (`/inventory`)

- ตั้งค่า (Value Pack, Mastery, รอบ/ชม. ฯลฯ) และคลังของ ผูกกับบัญชี เก็บใน DB ใช้ได้ทุกเครื่อง · ค่าที่เคยบันทึกในเบราว์เซอร์เวอร์ชันก่อนจะถูกย้ายให้อัตโนมัติครั้งแรกที่ล็อกอิน
- หน้า `/inventory` เพิ่ม/แก้จำนวนและต้นทุนที่จ่ายไป เห็นมูลค่าตลาดปัจจุบัน · ช่อง "มีอยู่แล้ว" ในแผนผลิตใช้ข้อมูลชุดเดียวกัน

## สูตรแปรรูป

- นำเข้าจาก bdocodex (mrecipes): หลอม บด ตากแห้ง เขย่า กรอง ตัดฟืน แปรธาตุอย่างง่าย ทำอาหารอย่างง่าย · ตัดสูตรที่หลอม/บดอุปกรณ์ (อาวุธ/เกราะ/เครื่องประดับ) ออกเพราะไม่ใช่งาน Life Skill
- Mastery แปรรูปในเกมไม่เพิ่มผลผลิตต่อชุด แต่เพิ่มจำนวนชุดที่ทำได้ต่อครั้ง (mass processing) ระบบแสดงตัวเลขนี้ในตั้งค่า ส่วน "รอบ/ชม." ให้กรอกตามความเร็วจริง
- แท็บ "ราชวัง": กล่องอาหาร/แปรธาตุราชวัง ราคาขายคือเงินจาก NPC ส่งของราชวัง (ช่อง "ราคาซื้อ" ในข้อมูลไอเท็ม) × (1 + โบนัส Mastery แปรธาตุ/ทำอาหาร) ไม่หักภาษี ไม่แสดงกำไร/ชม. เพราะมีโควตาต่อวัน
- ยังไม่รวม: สูตรผลิตของกิลด์/อาวุธ

## CSV / มือถือ

- ปุ่ม "ส่งออก CSV" ในหน้าคำนวณสูตร (ตารางตามตัวกรองปัจจุบัน) และในคลังของ · "นำเข้า CSV" คลังของ รับไฟล์ที่ส่งออกไป หรือไฟล์ที่มีคอลัมน์ ชื่อไอเท็ม/จำนวน (จับคู่ชื่อไทย/อังกฤษ)
- นำเข้ามี 2 โหมด: **ไฟล์ทับจำนวนเดิม** (ค่าเริ่มต้น นำเข้าไฟล์เดิมซ้ำได้ไม่ทบยอด) และ **ไฟล์บวกเพิ่มจากที่มี** (แคปคลังในเกมทีละหลัง ทำ CSV ทีละไฟล์ แล้วนำเข้าต่อกันให้ยอดรวมกัน) · ปุ่ม "ไฟล์ตัวอย่าง CSV" ให้ไฟล์แม่แบบ
- PWA: มี `manifest.webmanifest` + ไอคอน เปิดในเบราว์เซอร์มือถือแล้ว "เพิ่มไปยังหน้าจอหลัก" ได้ (ยังต้องออนไลน์)

## สแกนตลาด (`/market`)

- เก็บ snapshot ทั้งตลาด Asia (10,000+ ไอเท็ม พร้อมปริมาณซื้อขาย 14 วัน) ลง DB เมื่อมีคนเปิดหน้าและข้อมูลเก่ากว่า 5 นาที (รีเฟรชเบื้องหลังหลังส่งหน้าแล้ว) + cron รายวันจาก `vercel.json` (ตั้ง `CRON_SECRET` ใน env เพื่อล็อก endpoint)
- สร้างประวัติราคารายวันของเราเอง และทยอยดึงราคาย้อนหลัง 90 วันจาก API ทางการมาเติม (100 ไอเท็มต่อการเปิดหน้า) → คอลัมน์ "เฉลี่ย 90 วัน / เทียบปกติ / กำไรถ้าขายราคาปกติ / ROI"
- หน้าคำนวณสูตรใช้ราคาชุดเดียวกันจาก snapshot ถ้า snapshot ยังไม่มีจึงยิง API ตรง

## สูตรที่ใช้

- เงินที่ได้รับจริง = ราคาขาย × 0.65 × (1 + Value Pack 0.30 + Family Fame + แหวนพ่อค้า 0.05)
- ต้นทุนไอเท็ม = ถูกสุดระหว่าง ซื้อตลาด / ซื้อ NPC / ทำเอง (ผลรวมวัตถุดิบ ÷ ผลผลิตเฉลี่ย) โดยเลือกวัตถุดิบทดแทนที่ถูกที่สุดต่อหน่วยให้อัตโนมัติ
- ผลผลิตเฉลี่ย = (min+max)/2 ของสูตร × ตัวคูณผลผลิต (ตั้งค่าตาม mastery ของผู้ใช้)
